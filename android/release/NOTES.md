Couchcatch for Android.

**New in 1.1:**
- The game no longer slides under the navigation buttons or the status bar on Android 15 and later.
- The first screen can load a save code instead of starting a new game.

- **Plays offline:** the whole game is inside the app.
- **Saves stay on the phone:** Settings → Save code moves a save between devices, including from the claude.ai version.
- **Updates itself:** it pulls new game builds from this repository's `gh-pages` branch, but installs only builds signed with the project's update key (ECDSA P-256; the public key is compiled into the app). A branch, fork, pull request or tampered download can't push code to it. Details: [android/README.md](https://github.com/ML-Chen/couchcatch/blob/main/android/README.md).

**Install:** download `couchcatch.apk` below on the phone and open it. Android asks once to allow installs from your browser; you can turn that off again afterwards (Settings → Apps → Special app access → Install unknown apps).
